# Alarm Klock: positioning and feature list (Stage 3, awaiting Samay's approval)
One line: **The alarm that actually gets you out of bed: no ads, no missed rings, fair price.**

10x promise: reliability. Alarmy's #1 complaints are ads at wake-up, alarms that do not ring, and features locked behind a subscription. Alarm Klock never shows ads, rings with 3 backup follow-ups, and tells you before sleep if something would stop it.
